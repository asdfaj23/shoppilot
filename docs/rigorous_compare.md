# 严谨对比实验：Agent vs 纯 API 基线

## 实验设计（控制变量）

| 项 | 设置 |
|---|---|
| 题数 | 27 题（同套题库） |
| temperature | **统一 0.2**（消除温度偏差） |
| 模型 | 同一个 DeepSeek |
| 评分 | 同一套 `check_constraints()` 确定性规则（must_contain / must_not_contain） |
| 唯一变量 | Agent 有工具/知识库/编排/记忆 vs 基线裸问（只有一句 system prompt） |

## 总体结果

| 方案 | 完成率 |
|---|---|
| **ShopPilot Agent** | **96.3%（26/27）** |
| 纯 API 基线 | 40.7%（11/27） |

## McNemar 配对检验

| 配对类型 | 数量 |
|---|---|
| Agent 对 / 基线错（b） | 15 |
| Agent 错 / 基线对（c） | 0 |
| 不一致对总数 | 15 |
| **p 值（精确二项）** | **6.1e-05** |
| 结论 | **统计显著**（α=0.05） |

## 分场景对比

| 场景 | Agent 对/总数 | 基线对/总数 | 差距 |
|---|---|---|---|
| 选购推荐 | 7/8 | 2/8 | +5 |
| 商品对比 | 4/4 | 3/4 | +1 |
| 口碑解读 | 5/5 | 3/5 | +2 |
| 售后问答 | 5/5 | 3/5 | +2 |
| 拒答 | 4/4 | 0/4 | +4 |
| 多轮会话 | 1/1 | 0/1 | +1 |

## 解读

- Agent 完成率 96.3% vs 基线 40.7%，差值 +55.6%
- p=6.1e-05，**统计显著**（α=0.05）
- 统一 temperature=0.2 后，基线翻车不再是"温度放飞"导致——差距确来自系统设计（工具/知识库/编排/记忆）
- 基线翻车集中在：推荐类编造池外商品、拒答类该拒硬答、售后类答不准数字
